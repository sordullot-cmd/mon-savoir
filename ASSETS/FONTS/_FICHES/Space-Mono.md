# Space Mono

> Monospace au caractère **rétro-technique** : chasse fixe, formes géométriques carrées, détails marqués (terminaisons singulières, italique typée). À l'aise pour le code et les labels, mais aussi en titrage display pour un ton « techy / spatial ».

- **Forme / allure :** monospace géométrique, structure carrée et régulière, personnalité affirmée (clin d'œil rétro-futuriste). Contraste moyen.
- **À utiliser pour :** code, chiffres, labels, données ; titrage display à connotation technique/rétro ; projets clients (OFL).
- **À éviter pour :** longs paragraphes de texte courant (la chasse fixe fatigue à la lecture).
- **Voisines / alternatives :** [[PP Neue Montreal Mono]]
