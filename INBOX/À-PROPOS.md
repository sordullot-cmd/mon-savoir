# Inbox

**Balance tout ici sans réfléchir** : une idée, un lien, un screenshot, une note de réunion à la volée, un nom de font à checker.

Pas de rangement au moment de la capture → zéro friction.

## Règle

- Une fois par semaine (ou quand ça déborde), je vide l'Inbox :
  - soit je **range** l'élément dans son domaine (Unowhy / Sordulo / ICAN / Inspiration / Assets),
  - soit je le **transforme en fiche** depuis un template,
  - soit je le **supprime**.

> **Raccourci**: lance **`/ranger`** dans Claude Code → il vide l'Inbox tout seul (classe, déplace, crée les fiches, met à jour les index) et ne te demande que si c'est ambigu.

> Une Inbox vide = un cerveau tranquille.
