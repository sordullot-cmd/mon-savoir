courses et recette


courses :
- feculents : pate, patate / douches, lentilles, flocon d'avoine
- proteines : poulet, oeuf
- legumes : choux fleur, brocolis, oignon, ails
- fruits : banane, pommes
- laitier : skyr, lait, gruyere
- condiments : sucre, sel, miel, herbe de provinces / curry, beurre de cacahuete
- maison : papier toilette, sac poubelle, eponge, brosse a dents, dentifrice, rasoir

repas :
- patates douces = patate / douches
- lentilles = sel + poivre + saucisses
- plat japonais = riz + sauce soja + oeuf + poulet
- pates + poulet = pate + poulet + sauces tomates
- ramen chinois = nouilles + bouillon + oeuf + poulet + sauce soja
- petit dej = oeuf + flocon d'avoine
